# Face Mask Detection System

## Project Overview
Face Mask Detection System is a Deep Learning and Computer Vision based project that detects whether a person is wearing a face mask or not in real-time. The system uses Convolutional Neural Network (CNN) and OpenCV to identify masked and unmasked faces from images or live webcam feed.

## Features
- Real-time face mask detection using webcam
- Detects two classes:
  - With Mask
  - Without Mask
- Uses Deep Learning model for classification
- Fast and accurate prediction
- User-friendly interface

## Technologies Used
- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- Matplotlib
- CNN (Convolutional Neural Network)
- Jupyter Notebook
